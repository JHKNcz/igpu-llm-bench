## Practical conclusion

Keep the proven Vulkan + 16 GiB configuration for this model if speed is the
priority. The ROCm + 512 MiB unified-memory setup works, but measured throughput
was 14.7–18.7 tokens/s versus 24.8–33.0 on historical Vulkan DFlash runs. This
does **not** establish that Vulkan is universally superior or that shared memory
alone causes the difference. Before further long quality tests, constrain the
thinking budget and require complete final deliverables; additional
unrestricted-thinking runs would mostly measure time spent without an answer.
